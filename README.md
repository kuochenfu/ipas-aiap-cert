# iPAS 認證練習網站

經濟部產業人才能力鑑定（iPAS）的線上刷題練習網站，目前收錄**兩張證照、七個科目、1,972 題**。純前端 SPA，無後端、無資料庫，作答進度存在瀏覽器 localStorage。

🔗 **[線上使用](https://kuochenfu.github.io/ipas-aiap-cert/)**

> ⚠️ **關於題目來源**：只有標記為官方來源的題目取自 iPAS 官方公告試題與官方學習指引。
> 站上另有 1,113 題（補充新題 198 ＋ 評鑑節點新題庫 915）**由 LLM 命製**，目前僅通過格式、
> 節點配額與認知層級分布的自動測試，**內容正確性尚未經人工逐題複審**。這些題目在畫面上
> 一律標示「AI 命題・待複審」，請據此判斷可信度；發現錯誤歡迎開 issue。

## 練習模式

- **模擬考試**：3 份決定性試卷（同一份重開題目相同），單頁 50 題、計時作答，交卷後看成績與逐題檢討。每題 2 分、滿分 100 分，70 分（答對 35 題）及格。
- **刷題練習**：整個原題庫、依考卷原序，逐題作答後即時揭曉對錯與詳解，不計時。可依「全部／錯題／未答」篩選，支援跳題、進度續作與重置，題庫已分類的科目另有「節點表現」統計。
- **新題庫練習**：依官方評鑑內容節點分類的新題庫，每題附逐選項解析與判斷分界。
- **學習主題（延伸閱讀）**：AI 應用規劃師五科為官方學習指引的整理，AIoT 為備考整理（15 個節點、120 條縮寫速查）。含節點目錄、全文搜尋、展開收合、考前速記模式、從節點直達該節點題目與已讀標記。

錯題本會自動收錄模擬考交卷時答錯的題目，供刷題的「錯題」篩選使用。

## 指令

```bash
npm install          # 安裝相依套件
npm run dev          # 本地開發（http://127.0.0.1:5173/ipas-aiap-cert/）
npm run build        # 型別檢查 + 打包
npm run test         # 執行單元測試（24 個檔案、441 項）
npm run parse:papers # 解析 docs/markdown/*.md → src/data/past-exams/*.json
```

修改前後務必跑 `npm run build` 與 `npm run test`。

## 資料來源與管線

```
docs/raw/*.pdf  →  (pdftotext)  →  docs/markdown/*.md  →  npm run parse:papers  →  src/data/past-exams/*.json
```

- 原始 PDF 與中間產物置於 `docs/raw/`、`docs/markdown/`，**皆不納入版控**；進版控的是解析後的 JSON。
- 手寫的詳解、錯誤選項解析與原卷圖片轉錄放在 `src/data/explanations/<subjectId>.ts`，**與機器產物分離**——重跑解析只覆寫 `past-exams/*.json`，不會洗掉手寫內容。
- 原卷中的程式碼、console 輸出與資料表多以截圖呈現，一律人工轉錄為文字保存（可搜尋、可複製、手機可讀），不放圖檔。
- 逐題核對過程中發現的官方 PDF 缺陷與其他已知瑕疵，記錄於 `docs/coverage/bank-defects.md`。

`TypeScript` · `Vite` · `Vitest` · `GitHub Actions` · `GitHub Pages`
