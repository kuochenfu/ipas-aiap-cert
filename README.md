# iPAS AI 應用規劃師 — 題庫練習

iPAS「AI 應用規劃師」初級與中級認證的刷題練習網站，支援模擬考試與即時詳解兩種模式。

## 科目清單

| 等級 | 代碼 | 科目名稱 | 考試時間 |
|------|------|----------|----------|
| 初級 | 科目1 | 人工智慧基礎概論 | 75 分鐘 |
| 初級 | 科目2 | 生成式 AI 應用與規劃 | 75 分鐘 |
| 中級 | 科目1 | 人工智慧技術應用與規劃 | 90 分鐘 |
| 中級 | 科目2 | 大數據處理分析與應用 | 90 分鐘 |
| 中級 | 科目3 | 機器學習技術與應用 | 90 分鐘 |

## 練習模式

- **模擬考試**：隨機抽 50 題、計時作答、交卷後顯示成績；每題 2 分，滿分 100 分，70 分（答對 35 題）為及格線。
- **刷題練習**：自選題數、作答後即時顯示對錯與詳解、不計時；錯題自動加入錯題本以供複習。

## 計分規則

- 每科 50 題單選題（A/B/C/D）
- 每題 2 分，滿分 100 分
- 70 分及格（最多答錯 15 題）

## 指令

```bash
npm install          # 安裝相依套件
npm run dev          # 本地開發伺服器
npm run build        # 型別檢查 + 打包
npm run test         # 執行單元測試
npm run parse:papers # 解析 docs/markdown/*.md → src/data/past-exams/*.json
```

## 資料來源

題庫由官方歷屆公告試題解析而來。原始 PDF 置於 `docs/raw/`（私有、不納入版控），經 pdftotext 轉換為 `docs/markdown/*.md` 後，透過 `npm run parse:papers` 產生 `src/data/past-exams/*.json`（已提交）。各題詳解與補充新題為自行撰寫，分別存放於 `src/data/explanations/` 與 `src/data/generated/`。
