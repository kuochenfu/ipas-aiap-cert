# 題庫與學習筆記的已知缺陷

撰寫詳解與選項解析的過程中發現、但**不屬於當次任務範圍**的問題。集中記錄於此，避免只留在一次性的工作紀錄裡而流失。

每筆都經過獨立覆核（實作者提出、審查者查證來源），但**尚未經人工事實查核**。

## 答案鍵僅在特定讀法下成立的題目

這類題目不是詳解寫錯，而是題目本身有瑕疵。處理原則是**把成立的讀法明寫進詳解**，而不是假裝沒有歧義。

| 題目 | 問題 |
|---|---|
| `junior-ai-basics-guide-q020` | 「一組產品銷售量資料」最自然的讀法是每項產品一筆銷售數字，此時主力產品是離群值、**中位數**才對，與答案鍵（眾數）相反。只有把資料讀成「一筆筆記錄賣出的是哪項產品」的類別記錄，答案鍵才成立。原詳解另有實質錯誤（把「最大值」當成「最常出現」），已不予沿用。 |
| `junior-ai-basics-guide-q006` | 答案鍵成立於把「深度學習模型**中**」讀成「模型內部」而非「深度學習領域裡」。干擾項 A（增加資料量）依 `studyNotes.ts:973` 是過擬合的**真正**解法，就字面問法而言是正確答案。 |
| `junior-ai-basics-guide-q039` | 同一形狀：問「數據增強主要解決哪個問題」，答案鍵為 B（數據稀缺或不平衡），但干擾項 A（模型過擬合）依 `studyNotes.ts:874-876` 也是資料增強的真正效果。答案鍵靠「題目問的是哪一面」成立，而非 A 為假。 |
| `junior-genai-115-1-q50` | 答案鍵成立的前提（「可動範圍」）是從選項集合反推的，題幹並未明說；正解之所以成立，一部分是因為另外三個選項都沒碰到偏差的根源。 |
| `junior-genai-114-4-q16`、`q05` | q16 的正解與干擾項 B 是上下游關係而非對錯關係，只能靠「零附加前提」這條**撰寫者建構**的判準分開；q05 問「最大限制」，A/B/C 描述的都是真實困難，排序不是唯一可辯護的讀法。 |

| `junior-ai-basics-gen-q021` | 非瑕疵題，但鑑別度不如題面：準確率／召回率／精確率單看都各有盲點，答案鍵只在「最容易誤導」的讀法下唯一。 |
| `junior-genai-115-2-q04` | 有兩個選項各自為真，答案鍵僅在「應用層最完整」的讀法下成立。題幹首句以計費起頭是決定性線索。 |
| `junior-genai-115-2-q32` | 同上。正解是唯一同時描述產出的「運作方式」與「去向」的選項。 |

### `studyNotes.ts` 的「補充」段落與題庫循環（不是錯誤，是證據力的限制）

`junior-genai` 的核心名詞——LoRA、MCP、Chunking、知識蒸餾、同態加密、SynthID、AgentKit、情境感知代理、Graph Prompting、Encoder-Decoder、思維鏈——**全部**落在標示「補充 A／A2／A3｜題庫考點反推（非官方講義）」的段落；只有 TCO、邊緣運算、資料漂移在正文有涵蓋。那些卡片有**逐字抄答案鍵**的情形（`:2246` 對 AgentKit 的定義即 `115-1 q21` 選項 D 的原文；`:2201` 直接寫「115-1 Q06…正解為…」）。

因此：**用這些卡片去佐證這些題目的詳解，是循環論證**——一致只證明內部不矛盾，不構成正確性證據。撰寫或複審 `junior-genai` 的 115-1／115-2／114-4 內容時務必注意。

**但這條限制不適用於 guide 批次**（見 `docs/coverage/explanations-overhaul.md`）：`studyNotes.ts` 的 3.1（1468-1700）、3.2（1788-2037）、3.3（2300-2569）是**正文**，約 753 行正文對 445 行補充，而 `junior-genai` 的 29 題 guide 全部落在正文涵蓋範圍內。

## 用語不一致

GAN 的 Discriminator 在 `src/data/explanations/junior-ai-basics.ts` 內同時出現**判別器**（115-x 與 114-4 條目）與**鑑別器**（guide 條目）。guide 批用鑑別器是為了對齊該批題目的選項原文，屬正確取捨，但全庫需要一次統一決定。

**`studyNotes.ts` 本身也不一致**（先前此處誤記為「一律用判別器」）：`:320`／`:326`（L111 段）用判別器，`:1159`／`:1165`（L114 段）用鑑別器，兩份原始講義即如此；`:2231`、`:3179`、`:4365`、`:9285` 等處則用判別器。統一用語時要把 `studyNotes.ts` 一併納入。
