# 題庫與學習筆記的已知缺陷

撰寫詳解與選項解析的過程中發現、但**不屬於當次任務範圍**的問題。集中記錄於此，避免只留在一次性的工作紀錄裡而流失。

每筆都經過獨立覆核（實作者提出、審查者查證來源），但**尚未經人工事實查核**。

## 答案鍵僅在特定讀法下成立的題目

這類題目不是詳解寫錯，而是題目本身有瑕疵。處理原則是**把成立的讀法明寫進詳解**，而不是假裝沒有歧義。

| 題目 | 問題 |
|---|---|
| `junior-ai-basics-guide-q020` | 「一組產品銷售量資料」最自然的讀法是每項產品一筆銷售數字，此時主力產品是離群值、**中位數**才對，與答案鍵（眾數）相反。只有把資料讀成「一筆筆記錄賣出的是哪項產品」的類別記錄，答案鍵才成立。原詳解另有實質錯誤（把「最大值」當成「最常出現」），已不予沿用。 |
| `junior-ai-basics-guide-q006` | 答案鍵成立於把「深度學習模型**中**」讀成「模型內部」而非「深度學習領域裡」。干擾項 A（增加資料量）依 `studyNotes.ts:973` 是過擬合的**真正**解法，就字面問法而言是正確答案。 |
| `junior-genai-115-2-q04` | 有兩個選項各自為真，答案鍵僅在「應用層最完整」的讀法下成立。題幹首句以計費起頭是決定性線索。 |
| `junior-genai-115-2-q32` | 同上。正解是唯一同時描述產出的「運作方式」與「去向」的選項。 |
| `junior-genai-114-4-q19` | 題幹只排除語音辨識這一段，干擾項 A 仍是活的解釋。答案是「最能解釋此症狀者」，不是題幹已排除其餘可能。 |

| 題目 | 問題 |

## 重複或近重複的題目

同一份題庫內容重複，作答者會遇到實質相同的題目兩次。

- `guide-q002` 與 `guide-q009` — 選項**逐字相同**，答案同為 B
- `guide-q016` 與 `guide-q018` — 完全鏡像（負偏態／正偏態）
- `guide-q029` 與 `guide-q034` — 測同一個事實
- `guide-q031` 與 `guide-q035` — 測同一個事實

`junior-genai`：

- `guide-q020` 與 `guide-q025` — 選項集同構（基礎建設／目標／訓練／採購軟體，答案皆為「目標」那一項）

補充題（`gen-*`）：

- `junior-ai-basics-gen-q005` 與 `gen-q013` — 同一事實的鏡像題（由描述問名稱／由名稱問描述）
- `junior-ai-basics-gen-q015` 與 `gen-q025` — **兩對**干擾項重疊：「生成式無法用於分類」與「鑑別式一定較準／已取代」
- `junior-ai-basics-gen-q006` 與 `junior-genai-gen-q016` — **跨科目**重複，正解幾乎相同（few-shot）

## `src/data/studyNotes.ts` 的錯誤

| 位置 | 問題 |
|---|---|
| `studyNotes.ts:551` | 稱四分位距「與全距有一樣的缺點」，而全距的缺點列有「會受極端值影響」。IQR 的兩個端點由**排名**決定、頭尾各四分之一不進入計算，正是**抗**離群值的。題庫的詳解（`guide-q019`）與此處敘述在實質上矛盾。 |
| `studyNotes.ts:617` | 「拒絕 H0 而 H0 為真」標為「Type II 錯誤（α）」，應為**型一錯誤**。 |
| `studyNotes.ts:1004` | 交叉引用「114-4 Q37」為資料漂移題，但該題實為時間序列抽樣題；`studyNotes.ts:696` 的引用是正確的。 |

## 用語不一致

GAN 的 Discriminator 在 `src/data/explanations/junior-ai-basics.ts` 內同時出現**判別器**（115-x 與 114-4 條目）與**鑑別器**（guide 條目）；`studyNotes.ts` 一律用判別器。guide 批用鑑別器是為了對齊該批題目的選項原文，屬正確取捨，但全庫需要一次統一決定。

## `src/data/explanations/junior-ai-basics.ts:88`

把貝氏網路稱為「鑑別/分類或推論模型」，與 115-2 稱單純貝氏為生成式模型並非真衝突（兩者對象不同），但同時讀到的學習者可能誤解為衝突。
