## 做了什麼（依時序）

1. **核心練習網站**：仿 `aiatcl-cert-practice` 的純前端 Vite + TS 靜態站。初級 2 科、中級 3 科分開；解析 7 份官方公告試題成 350 真題（含官方答案）；模擬考試與刷題兩模式；localStorage 錯題本。初級科目1 補齊 100 題詳解 ＋ 12 題新題。部署到 GitHub Pages。
2. **學習主題（延伸閱讀）**：依官方評鑑範圍建立 5 科 18 個評鑑主題，每主題附經 HTTP 驗證的外部閱讀連結（含台灣官方來源）。首頁入口 → 獨立分組頁面。
3. **暖色亮色主題**：比照參考站，從深色改為米白＋松綠的亮色系。
4. **單頁三份模擬試卷 ＋ 全題庫刷題**：模擬考試改為「選 3 份試卷 → 單頁 50 題作答（就地選取、不重繪）→ 單頁檢討」；刷題改為涵蓋整個題庫、依考卷原序。
5. **修正刷題題數標籤**：模式選單由寫死「20 題」改為動態顯示實際題數。

## 流程

每個功能都走：`brainstorming（釐清＋設計）→ 寫 spec → 寫 plan → 實作（subagent-driven 兩階段審查 或 直接實作）→ 瀏覽器實測 → 合併 → 推送自動部署`。所有 spec/plan 留存於 `docs/superpowers/`。

## 做得好的地方

- **資料來源分離**：真題（解析產生的 JSON）、詳解（手寫 map）、新題（手寫陣列）三者分檔，載入時合併。重跑解析腳本不會覆蓋手寫內容——這個決定多次證明其價值。
- **解析器務實處理真實雜訊**：全形答案字母、跨頁延續、一行多選項、跨題共用引文等，皆以小而聚焦的函式處理並有測試；350 題僅 1 題因原始 PDF 為圖片而選項為空。
- **TDD ＋ 不變式測試**：計分、科目目錄、解析輸出、錯題本、抽題、渲染跳脫、試卷決定性，皆有測試守護。
- **瀏覽器實測抓到真 bug**：多個只有實際操作才會浮現的問題在 review/實測階段被攔下。
- **外部連結逐一 HTTP 驗證**：避免延伸閱讀出現死連結。
