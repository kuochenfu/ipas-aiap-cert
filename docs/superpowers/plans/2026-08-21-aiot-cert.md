# AIoT 應用工程師（初級）新增為獨立證照 — 實作計畫

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在本站新增第二張證照「AIoT 應用工程師（初級）」，與 AI 應用規劃師在導覽與資料層完全分離，首批內容為官方學習指引科目一的 80 題練習評量。

**Architecture:** 沿用既有的 `parseStudyGuide` 管線，以 `PaperEntry` 上的選用設定開關處理 AIoT 指引的三處差異（半形選項標記、逐項選項解析、節點與來源），預設行為不變以保證既有五科的解析產物逐位元組相同。UI 端在 `home` 與 `level` 之間插入 `cert` 視圖，`Subject` 新增 `cert` 與 `mockExam` 兩個欄位。

**Tech Stack:** TypeScript、Vite、Vitest、tsx（解析腳本）。無新增相依套件。

**Spec:** `docs/superpowers/specs/2026-08-21-aiot-cert-design.md`

## Global Constraints

- 所有動態文字一律先經 `src/ui/escape.ts` 的 `escapeHtml`。
- localStorage key `ipas-aiap-misses` 與 `ipas-aiap-drill-progress` **不得更名**。
- `src/data/past-exams/*.json` 為機器產物，只能由 `npm run parse:papers` 產生，不得手改。

- AIoT 節點碼格式：`A{主題}.{內容} {名稱}`，例 `A1.1 AI 基礎概念`。

export type GuideSection = { code: string; count: number };

export type PaperEntry = {
  file: string;

  examCode: string;
  examLabel: string;

  perChoiceExplanations?: boolean;
  source?: "past-exam" | "generated" | "study-guide";
  /** 依出現順序列出各小節的節點碼與題數，用於回填 topic。 */
  sections?: GuideSection[];
};

在 `scripts/parse-core.ts`：把寫死的 `guideChoiceStart` 改為依 `choiceMarker` 選用的兩個常數，`parseStudyGuideQuestionDrafts` 與 `parseStudyGuideAnswerDrafts` 都接受它作為參數；`parseStudyGuide` 依 `ctx.source ?? "past-exam"` 決定 `source`，依 `ctx.sections` 依序回填 `topic`（無 sections 時維持 `"未分類"`）。

```ts
const GUIDE_CHOICE_START = {
  fullwidth: /^（([A-D])）\s*(.*)$/,
  halfwidth: /^\(([A-D])\)\s*(.*)$/,
} as const;

const topicForIndex = (sections: GuideSection[] | undefined, index: number): string => {
  if (!sections) return "未分類";
  let seen = 0;
  for (const section of sections) {
    if (index < seen + section.count) return section.code;
    seen += section.count;
  }
  return "未分類";
};
```
