# 刷題進度續作與跳題 — 設計

日期：2026-08-11

## 問題

刷題練習每次進入都從第 1 題開始。`session` 只存在記憶體，離開畫面即歸零，題庫最大的科目有 222 題，使用者無法分次刷完。

連帶的問題：現有的「全部／錯題／未答」三個篩選器實際上沒有作用——每次進入時所有題目都是未答狀態，「錯題」永遠是 0。

## 目標

1. 刷題進度（目前題目與作答紀錄）跨場次保留，再次進入時自動續作。
2. 可直接跳到指定題號。
3. 提供重置進度的出口。

## 非目標

- 模擬考試不存進度。考試有計時與交卷語意，續作需處理剩餘時間等問題，不在本次範圍。
- 不做跨裝置同步（本站無後端）。
- 不改動錯題本（`ipas-aiap-misses`）的行為與 key。

## 資料模型

新增 `src/state/drillProgress.ts`，比照 `storage.ts` 的寫法：try/catch 包裹、格式不符一律回退為空值，不讓損壞的 localStorage 內容導致白畫面。

localStorage key：`ipas-aiap-drill-progress`（新增，不動既有 key）。

```ts
export type DrillProgress = {
  questionId: string;                    // 目前所在題目的 id
  answers: Record<string, ChoiceId>;     // 題目 id → 選項
};
// 儲存格式：Record<subjectId, DrillProgress>，五科共用同一個 key
```

**以 `questionId` 而非索引記錄位置。** 題庫會持續擴充新題，索引會在題庫變動後指向錯的題目；id 則穩定。讀取時以 id 反查索引，若找不到（該題已被移除）回退至索引 0。`answers` 本來就以 id 為 key，天生耐得住題庫變動；讀取時過濾掉不存在於當前題庫的 id。

資料量：最大科目 222 題，約 7KB／科，五科約 35KB，對 localStorage 5MB 上限無壓力。

寫入時機：每次作答、每次換題（含跳題）。

## UI

### 刷題畫面

在現有篩選器列的右側加入跳題與重置：

```
[全部 222] [錯題 12] [未答 85]        跳至 [___] 題  [重置進度]
```

- 輸入框接受 1 到題庫題數的整數。
- 觸發方式：按鈕點擊，或在輸入框按 Enter。
- 超出範圍、非數字、空白一律忽略，不彈錯誤訊息（維持全站無彈窗的互動風格）。
- 「重置進度」清除該科進度與作答紀錄，回到第 1 題、篩選器回到「全部」。

### 模式選單

刷題卡片加一行進度提示，讓使用者在進入前就知道會續作：

```
刷題練習
全部 222 題・即時對錯與詳解・不計時
上次進度：第 137 題・已作答 136 題
```

無進度時不顯示這一行。

## 行為決定

1. **跳號針對全題庫原序**（即考卷原序的第 N 題），不是「當前篩選下的第 N 題」。
2. **跳題時若目標題不符合當前篩選，自動切回「全部」**，否則畫面不會有反應，形成鬼打牆。
3. 續作進入時，`reveal` 依既有的 `revealForCurrent()` 規則計算——該題已作答就揭曉，未作答則否。

## 實作路徑

| 檔案 | 變更 |
|---|---|
| `src/state/drillProgress.ts` | 新增：`loadDrillProgress` / `saveDrillProgress` / `clearDrillProgress` |
| `src/main.ts` | 進入刷題時載入進度；作答與換題後寫入；處理 `jump` 與 `drill-reset` |
| `src/ui/render.ts` | 篩選器列加跳題輸入與重置鈕；`renderModePicker` 加進度提示 |
| `src/styles.css` | 跳題列的樣式 |

**事件處理**：跳題與重置沿用既有的 `data-nav`（值為 `jump` 與 `drill-reset`），**不新增 data-\* 屬性**，以避開 `main.ts` 事件委派選擇器清單漏列的既知陷阱。Enter 鍵需新增一個 keydown listener——這是本次唯一新增的事件路徑。

## 測試

- `drillProgress` 讀寫往返；損壞 JSON、非物件、缺欄位皆回退為空值。
- 題庫變動的容錯：`questionId` 不在題庫中時回退索引 0；`answers` 中不存在的 id 被過濾。
- 跳號邊界：0、負數、超出上限、非數字、空白皆不改變狀態；合法值正確設定索引。
- 跳到被當前篩選排除的題目時，篩選器切回 `all`。
- `renderModePicker` 有無進度時的兩種輸出。
- 既有 106 個測試需維持通過。
